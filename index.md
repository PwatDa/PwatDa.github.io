### CPSC 120 Labs

* Lab 01

    Lab 1 was the first assignment I had to take, involving the classic goal that every fledgling programmer has to complete: Making the Hello World program! Although this wasn't the first time I ran some code containing "Hello World!" in it, this lab signalled my first use of C++ as a coding language and Linux as an operating system, alongside first learning about and using Git and Github. As simple as it was, it is always a satisfying moment seeing Hello World appear on screen for the first time on a study you are starting to learn.

* Lab 06

    Lab 6 was an assignment that comprised of two parts: The first part was about making funny statements using given arguments, while the second part was making a functioning program out of if statements that could score Blackjack. As an avid enjoyer of card-games, working on the second section of the lab was quite cool, and I enjoyed the process behind it - Using if statements and command arguments to check cards and their scores. It also helped that I had good company while testing the programs.

* Lab 12

    Lab 12 was the very last in-person assignment for the semester, and it debatably had the coolest objectives (It involved media production and random number generation). Compared to all the previous labs which involved looking at walls of text and the neverending process of compliling and running, this was quite the fun change. In some ways, the lab reminded me of my time doing web dev/dsgn. To me, the animation work and number generation was a good learning experience.
